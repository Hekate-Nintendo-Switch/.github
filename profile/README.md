## FAQ

**1. What is Hekate?**

Hekate is an open-source graphical bootloader and firmware patcher for Nintendo Switch. It combines boot management with system utilities.

**2. What is Nyx?**

Nyx is Hekate's graphical user interface. It provides touchscreen access to boot options, configuration, and system tools.

**3. Is Hekate custom firmware?**

No. Hekate is a bootloader and firmware patcher. It can launch custom firmware such as Atmosphère, but it is not itself a complete custom firmware environment.

**4. Can Hekate launch Android and Linux?**

Yes. The project supports booting compatible Android and Linux environments, in addition to custom firmware and payload tools.

**5. Where can I find the latest version?**

The official GitHub Releases page provides Hekate downloads and version-specific release notes. Check the release information for supported system software before updating.
